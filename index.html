Wie optimiere ich ein CLIP-Modell besonders effizient?

// titel der arbeit Optimierungsstrategien für CLIP-basierte Text-zu-Video-Retrieval-Systeme

Ich habe das KI-Modell CLIP trainiert, damit es per Textbeschreibung die passende Szene in Videos findet. Dabei wollte ich herausfinden, wie man es möglichst effizient optimieren kann und habe verschiedene Optimierungsstrategien wie Fine-Tuning und Interpolation verglichen und gemessen, wie weit man gehen kann, bevor es auf fremden Daten schlechter wird. Dafür habe ich einen Prototyp in Python mit PyTorch trainiert und knapp 200 Messungen ausgewertet, alles auf meiner eigenen Grafikkarte.

  • Training Fine-Tuning verbessert das Modell auf den Trainingsdaten. Mischt man die ermittelten Gewichte von Original und Fine-Tuning um einen bestimmten Wert, erhält man eine Mischung aus beiden. Was besser performt, entscheidet der Mischfaktor.
  • Frame Sampling Frame Sampling beschreibt die Wahl der Frames aus einem Video für die Analyse. Das Ergebnis zeigt, dass ein Bild pro Sekunde Video reicht: Doppelt so viele Frames bringen kaum einen Vorteil, halb so viele kosten etwas Genauigkeit.
  • Effizienz Partielles Fine-Tuning dauerte nur 55 % so lange wie das vollständige und erreichte beinahe dieselben Ergebnisse.
